# My Portfolio Website

## About the Project
This is a personal portfolio website built using Python and Flask.
It displays my skills and projects in a clean and responsive design.

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Project Features
- Home section
- About Me section
- Skills section
- Projects section
- Contact section
- Responsive design

## Installation

1. Clone or download the project.
2. Install the required packages:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open your browser and visit:

   http://127.0.0.1:5000
